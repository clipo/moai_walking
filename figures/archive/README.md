# Archived Figure Outputs

This folder contains older versions of figure outputs that have been superseded by newer versions.

## Contents

### Older Figure Naming Convention
The files with lowercase "figure" prefix (e.g., `figure11_*.png`) are from earlier runs and have been replaced by the uppercase "Figure_" versions in the main figures directory.

### Archived Files Include:
- `figure11_transport_failure_expectation.*` - Older Figure 11 outputs
- `figure12_distribution_analysis.*` - Older Figure 12 outputs  
- `figure13_size_analysis.*` - Older Figure 13 outputs
- `figure3_com_*` - Older Figure 3 outputs
- `figure5_*` - Older Figure 5 outputs (before intact moai filtering)
- `transport_failure_expectation.*` - Duplicate of Figure 11

## Current Naming Convention

The latest figures in the main directory follow this pattern:
- `Figure_2_moai_ratio_comparison.*`
- `Figure_3_com_distribution.*`
- `Figure_5_intact_road_moai.*`
- `Figure_11_transport_failure_expectation.*`
- `Figure_12_distribution_analysis.*`
- `Figure_13_size_analysis.*`
- `moai_analysis_final.*` (Python 3D analysis)
- `moai_analysis_plotly.*` (Python interactive)
- `moai_analysis_interactive.html` (Python interactive HTML)

Each figure typically includes:
- `.png` - High resolution (600 dpi)
- `_preview.png` - Low resolution (150 dpi) 
- `.svg` - Vector format
- `.pdf` - PDF format (for some figures)
- `.csv` - Associated data files
